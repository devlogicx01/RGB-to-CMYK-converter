# RGB to CMYK Converter

A simple C program that converts RGB color values into CMYK format using mathematical conversion formulas.

---

# Features

- Convert RGB values to CMYK
- Input validation for RGB range (0–255)
- Handles pure black `(0,0,0)` separately
- Repeated conversions using loop
- Beginner-friendly C project

---

# Technologies Used

## C Programming Language

## Standard Libraries

- `stdio.h`
- `math.h`

---

# How It Works

The program:

1. Takes RGB values from the user
2. Validates the input range
3. Converts RGB to CMYK using formulas
4. Displays the result
5. Allows multiple conversions
